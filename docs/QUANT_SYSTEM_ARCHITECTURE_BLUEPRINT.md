## 二、 实证复盘：统一参数为何在不同标的上失效？

在 `backtest/run_backtest_batch.py` 的实测中，统一默认参数（资金 10 万、单笔风险 1%、固定止损 4%、移动止损 2.5%、分位阈值 80%）导致了截然不同的结果：

| 标的代码 | 市场 / 类型 | 日均波动率 | 信号数 / 交易数 | 收益率 / 胜率 | 失败 / 成功根因剖析 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **00700**<br/>(腾讯控股) | 港股 / 高价蓝筹 | 2.32% | 4 信号 / **0 交易** | 0.00% / N/A | **一手资金约束导致 0 交易**：单笔 1% 风险预算（1000元）对应 4% 止损只能买 48 股，港股一手为 100 股（约 5 万元），被整手四舍五入强制抹零。 |
| **300418**<br/>(昆仑万维) | A股 / 高波成长 | 4.33% | **0 信号** / **0 交易** | 0.00% / N/A | **高波动被硬止损逻辑完全误杀**：单日波动已超 4%，Kronos 预测的下探自然偏大，直接触发 `depth >= 2.0`（下探过深）一票否决，买入信号归零。 |
| **600036**<br/>(招商银行) | A股 / 低波红利 | 1.11% | 15 信号 / 14 交易 | -1.26% / 50% (盈亏比 0.58) | **交易摩擦侵蚀微小波幅**：日波动仅 1%，4% 止损过宽无法及时离场，A 股印花税与佣金吞噬利润，盈亏比失衡。 |
| **AAPL**<br/>(苹果公司) | 美股 / 中波龙头 | 1.68% | 24 信号 / 12 交易 | **+4.08%** / 75% (盈亏比 2.89) | **参数天然契合**：1 股起买、无印花税、T+0、中等波动，刚好落在 4% 止损与资金模型的最佳舒适区。 |

**核心结论**：一刀切的固定参数不仅无法达到最优，还会因为交易制度摩擦与统计分布差异，直接抹杀整个资产类别的交易机会。

## 三、 参数设计方法论：风格群组 vs 个股寻优

### 1. 为什么坚决反对“单只股票过度寻优”？
- **自由度灾难（Degrees of Freedom Disaster）**：单只股票在 120 天内通常仅有 10~20 笔交易。在 15 笔交易上优化 4 个参数，在统计学上毫无显著性；
- **过拟合与数据窥探（Data Snooping）**：寻优出的“神级参数”本质上是在记忆历史随机噪音或特定反弹低点，在未来的市场状态漂移（Regime Shift）中必然遭遇样本外崩塌。

### 2. 业界推荐的“第三条道路”
- **宏观按风格群组配置超参数**：高弹性成长大类使用短时界、宽止损模板；低波防守大类使用长时界、紧止损模板；
- **微观使用无量纲特征自适应**：
  $$\text{动态止损阈值}_t = k_{\text{style}} \times \text{ATR}_{14}(t)$$
  用同一套逻辑，自动根据股票当前真实波幅伸缩，无需人工为每只股票硬编码死数字；
- **贝叶斯收缩估计（Bayesian Shrinkage）**：若必须针对个股校准，强制将单股历史最优参数向所属群组的均值锚点进行收缩，滤除特质性噪音。

## 四、 维度协同：行业分类与风格分类的正交解耦

行业分类与风格分类绝非“二选一”，而是**各司其职的双层正交体系**：

```
                      ┌────────────────────────────┐
                      │ 行业维度 (宏观业务与周期)    │
                      └─────────────┬──────────────┘
                                    │
                    ┌───────────────┴───────────────┐
                    ▼                               ▼
            半导体板块 (上限 30%)             电力红利板块 (上限 30%)
                    │                               │
                    ▼                               ▼
            行业内部打分排名                  行业内部打分排名
            (提取纯Alpha，剔除行业Beta)        (提取纯Alpha，剔除行业Beta)
                    │                               │
                    └───────────────┬───────────────┘
                                    ▼
                      ┌────────────────────────────┐
                      │ 风格维度 (微观统计与交易规则)│
                      └─────────────┬──────────────┘
                                    │
                    ┌───────────────┴───────────────┐
                    ▼                               ▼
            高弹性风格 (ATR > 3%)            低波稳健风格 (ATR < 1.8%)
            - 预测时界: 2~5 天               - 预测时界: 10~25 天
            - 止损: 1.8 * ATR 宽止损         - 止损: 2.0% 紧止损
            - 移动止盈: 1.2 * ATR            - 宽持仓容忍，降低换手率
```

- **行业层（上层）**：解决**资产配置比例（防单一板块暴跌）**与**行业内相对强弱选股**；
- **风格层（下层）**：解决**止损多宽、持有几天、单手资金门槛**等微观执行细节。

## 五、 前置基石：因子挖掘、清洗与有效性筛选库

作为全流程的“水源地”，前置因子库负责为 `rankingmethod` 提供精纯的特征输入：

### 1. 因子池构建（Factor Zoo）
- **动量与反转**：多周期收益率差（12-1月、5日反转）、RSI、PPO 柱状图、价格与均线偏离度（SMA Ratio）；
- **波动率与风险**：归一化 ATR（NATR）、布林带带宽（BB_Width）、下行波动率比率；
- **资金流与流动性**：成交额对数、成交量偏离度、Amihud 非流动性指标；
- **财务质量（Point-In-Time）**：ROE 环比变动、毛利率增速、经营现金流/净利润。

### 2. 四道准入硬门槛
1. **Rank IC 检验**：全样本截面 Rank IC 均值必须满足 $|IC| \ge 0.03$；
2. **ICIR 稳定性**：$ICIR = \frac{\text{Mean}(IC)}{\text{Std}(IC)} \ge 0.5$；
3. **单调性检验**：5 分层多空组合累计净值曲线必须呈现严格单调展开；
4. **正交去重**：两两特征相关系数超过 0.60 时，仅保留 ICIR 更高的因子，输出 15~20 个互不重叠的高信噪比特征。

## 六、 中枢连接：`rankingmethod` 横截面选股引擎

负责从海量股票池快速锁定 Top 10~15 只最具爆发力且相互独立的标的：
- **LambdaRank 学习排序**：直接优化预测序列与真实未来收益的相对次序（NDCG），避免绝对数值回归的过拟合；
- **行业持仓上限 (`sector_limit = 1`)**：强制限制每个行业最大入选数量，杜绝同一赛道过度集中；
- **成对相关性过滤 (`corr_thresh = 0.85`)**：动态计算标的间历史收益率相关系数，确保组合低相关；
- **持仓粘性奖励 (`persist_bonus = 0.10`)**：为当前已持仓股票提供微调加分，压制不必要的高频调仓摩擦。

## 七、 核心大脑：`Kronos` 时间序列微观路径推演

仅对 `rankingmethod` 选出的候选池启动深度推演，兼顾高精度与计算效率：
- **自回归轨迹预测**：输出未来 1~20 天的完整收盘价分布与置信区间；
- **预测波峰 (`pred_path_max`)**：确定潜在收益上限，作为主动移动止盈的目标锚点；
- **预测下探 (`pred_min_down`)**：评估潜在下行回撤深度，动态缩放初始开仓仓位（Position Scale）；
- **动态最优时界 (`optimal_horizon`)**：模型根据波峰出现的相对位置，自适应决定当前交易的最优持有周期。

## 八、 安全气囊：`TradingAgents` 多智能体定性排雷与 CIO 白皮书

### 1. 架构定位：定性排雷与一票否决（Pre-Trade Veto）
平时不参与日常运算，仅在 Kronos 发出拟买入指令时，对最终 3~5 只标的进行按需异步审查：
- **剪裁冗余节点**：移除通用大模型的 Technical Analyst（避免低劣的 K 线幻觉），保留 `News Analyst`、`Fundamentals Analyst`、`Bear Researcher`；
- **Pydantic 强类型输出**：
  ```python
  class PreTradeAuditResult(BaseModel):
      stock_code: str
      verdict: Literal["APPROVE", "VETO", "WARN"]
      veto_reason: str | None = None
      red_flags: list[str]
      sentiment_score: float
      fundamental_health: Literal["HEALTHY", "NEUTRAL", "DANGEROUS"]
      one_sentence_summary: str
  ```
  在量化撮合代码中直接按 `audit.verdict == "VETO"` 实现零歧义物理熔断。

### 2. 认知合成：《每日量化投资决策白皮书》
通过“数据插桩注入 + 首席投资官（CIO）提示词模板”，将前序模块的真实硬核数字与定性逻辑串联为标准化报告：
- **大盘资产水位与资金敞口**
- **今日调仓指令明细单**（买卖方向、股数、挂单价、目标波峰、硬止损线）
- **标的深度三维论证**（因子排名 + K线推演 + 催化剂背书）
- **风险排雷与否决档案**（被一票否决的标的及原因）

## 九、 撮合与执行：`KronosBacktesterPro` 的保留与演进

### 1. 坚定保留专有内核
通用框架（Backtrader、VNPY）无法理解 Kronos 的大模型专属输出（波峰、下探、动态时界、去偏）。`KronosBacktesterPro` 深度贴合真实市场机制（T+1、印花税、最低佣金、整手规则、涨跌停），是核心专有资产，无需替换。

### 2. 组合级演进方向
将当前的“单标的独立回测”升级为**“时间步进驱动的统一共享现金池（Global Portfolio Ledger）”**：
- 每日统一扣减建仓资金，动态争抢现金池；
- 盘中各自触发 ATR 止损或波峰止盈，资金实时回流至总账户；
- 真实测算全组合的夏普比率、卡玛比率与资金闲置率。

### 3. 实盘解耦与微服务化架构 (V2.0 工业化落地)
已在 `backtest/` 完成全模块解耦重构，通过统一经纪商抽象实现「同一套策略代码，回测与实盘无缝复用」：
- **统一经纪商接口**：[`BaseBroker`](file:///Users/jyy/Documents/github_projects/Kronos/backtest/execution/broker_base.py) 统一定义报单、撤单、持仓与账户净值查询。
- **仿真撮合内核**：[`SimulatedBroker`](file:///Users/jyy/Documents/github_projects/Kronos/backtest/execution/simulated_broker.py) 全真模拟港美股/A股滑点、佣金、印花税、整手申报与跌停封死。
- **港美股实盘网关**：
  - 富途证券：[`FutuBrokerAdapter`](file:///Users/jyy/Documents/github_projects/Kronos/backtest/execution/live_broker_adapter.py)（对接 Futu OpenD，覆盖港股/美股正股交易与仿真测试）；
  - 盈透证券：[`InteractiveBrokersAdapter`](file:///Users/jyy/Documents/github_projects/Kronos/backtest/execution/live_broker_adapter.py)（对接 IBKR API / TWS / Gateway，覆盖美股/港股全品种与日内高频 Bar）。
- **多时间粒度支持**：[`TimeFrame`](file:///Users/jyy/Documents/github_projects/Kronos/backtest/core/types.py) 支持 15m / 30m / 60m / 日线多周期回测，自动根据各交易所交易时段（美股 6.5h / 港股 5.5h / A股 4.0h）精准折算年化因子与夏普比率。
- **策略可插拔基类**：[`BaseStrategy`](file:///Users/jyy/Documents/github_projects/Kronos/backtest/strategies/base.py) 支持用户 30 行代码编写任意自定义量化策略，策略与撮合引擎完全解耦。
